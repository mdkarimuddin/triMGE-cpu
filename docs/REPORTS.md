# Automated reports

The pipeline writes **two report stages** after classification.  
They are generated by `trimge-cpu-pipeline` (default) or `trimge-cpu-report`.

Install matplotlib extras first:

```bash
pip install -e ".[report]"
```

## Layout

```text
03_report/   (or your -o directory)
  01_three_class/
    tables/
    figures/
  02_pp_subtype/
    tables/
    figures/
  pipeline_summary.json
  README.md
```

Figures are written as **PNG and PDF**.

---

## Step 1 — Three-class MGE report

**Input:** all rows in `predictions.tsv`  
**Classes:** phage / phage-plasmid / plasmid

### Tables (`01_three_class/tables/`)

Typical files:

| File | Content |
|------|---------|
| `three_class_counts.csv` | Counts and % per class |
| Confidence / length summaries | Per-class confidence and length statistics |
| Copy of predictions used | Traceability |

### Figures (`01_three_class/figures/`)

Bar charts, distribution / box plots, and composition (donut/pie-style) plots summarizing the three-class calls.

---

## Step 2 — Phage-plasmid subtype report

**Input:** rows where `mge_class == phage_plasmid` only  
**Labels:** up to 15 subtypes (e.g. P1, PiSa, N15, Singleton, …)

If no phage-plasmids were predicted, Step 2 still runs but tables/figures will be empty or minimal.

### Tables (`02_pp_subtype/tables/`)

| File | Content |
|------|---------|
| PP-only prediction table | Subset of sequences called phage-plasmid |
| Subtype counts | Counts and % per subtype |

### Figures (`02_pp_subtype/figures/`)

Subtype composition and distribution plots.

---

## Regenerating reports

From an existing run:

```bash
trimge-cpu-report \
  -i /path/to/run/02_predictions/predictions.tsv \
  -o /path/to/run/03_report \
  --steps 1,2
```

Or via the easy pipeline without re-classifying:

```bash
trimge-cpu-pipeline \
  --fasta /path/to/run/01_combined/all_sequences.fna \
  --workdir /path/to/run \
  --models-dir models \
  --skip-classify
```

---

## Skipping reports

```bash
trimge-cpu-pipeline ... --skip-report
```

Use this for batch classification when you only need `predictions.tsv`.
